#+title: PyGioNav

A Python rewrite of Howard Rogers' Giocoso music player, streaming from a
Navidrome server (Subsonic API) instead of local FLAC files. Picks albums
at random (optionally filtered by artist, genre, album, duration, or
library), pre-downloads every track so ffmpeg can play them gaplessly,
tracks plays in SQLite, and scrobbles through Navidrome.

Full feature list, configuration and usage are in [[file:README.md][README.md]].
